# 05｜Demo 實作說明

本文件記錄 `demo/` 依照 [04-mma-kids-spec.md](04-mma-kids-spec.md) 實作時，**與規格書不同或補充的地方**。其餘一律照規格書。

## 0. 新增：初次設定（打開 Demo 第一個畫面）

1. **媽媽先設定**（DAWHO › 親子 › 初次設定）：每週零用錢 $500／$800／$1,000、轉帳時間（星期＋時間）、配對比例 1:1／1:0.5／1:2、每週配對上限（$100／$200／$300）、這個夢想的配對上限（$300／$600／$900）
2. **小安接著設定**（MMA Kids）：儲蓄／需要／想要三罐子比例，可選預設組合或用 ± 每次調 5%，合計必須 100% 才能按「開始使用」；畫面即時換算成每週金額
3. 設定完成後，所有數字依這組設定計算；家長手機上方的「重新設定（示範）」可以重來

## 1. 新增：日常錢包（簡化版）

| 項目 | 作法 |
|---|---|
| 首頁大數字 | **可以用的錢**＝需要罐＋想要罐 |
| 三罐子 | 儲蓄／需要／想要，預設 30% / 35% / 35%；首頁一律顯示**金額**，比例放在小字。可在「錢包 › 預算設定」修改，下次入帳套用 |
| 儲蓄罐 | 就是夢想基金的「我存的」：零用錢的儲蓄份自動存進目前的夢想，**不產生配對** |
| 需要罐 | 交通、文具、午餐。付款時依店家類別自動扣這一罐 |
| 想要罐 | 飲料、零食、娛樂。只有花想要罐、金額 ≥ $50 時才跳出「買下去／存起來」 |
| 罐子不夠 | 會問「要用另一個罐子的錢補嗎？」，不直接擋下 |
| 分享罐 | 已拿掉 |
| 底部分頁 | 規格書的「帳本」改名為「錢包」，內含「收支紀錄」與「預算設定」兩個頁籤 |
| 任務獎勵 | 不出現在收支紀錄中（任務＝非金錢禮物，不經過帳戶） |

會配對的只有孩子主動存的錢：付款前選「存起來」、把需要／想要罐剩下的存進夢想（紅包預設不配對）。

## 2. 數字與流程的修正

| 項目 | 規格書 | Demo | 原因 |
|---|---|---|---|
| 本週配對起始值 | 家長端寫「本週配對保留 $50（已達上限）」 | 起始為 **$0**，付款選「存起來」後才開始累計 | 一開始就達上限的話，「存起來」不會有配對 |
| 達標示範 | 需多週累積 | 「快轉：存到只差一點」：媽媽保留 $550、我存的 $1,150，再存 $50 即達標（預設設定下） | 實際需要好幾個週日 |
| 預計達成日 | 固定寫 12/27 | 依每週儲蓄（零用錢儲蓄份＋每週配對上限）計算「約 N 週後達成」 | 數字隨操作與設定變動時仍前後一致 |
| 配對款 | 「先保留在家長帳戶」 | 一律寫「**圈存**在家長帳戶」 | 依討論決定（方案 A） |
| 提前領出 | 未說明配對款 | 領出的金額依比例**解除對應的配對圈存** | 半途領出就拿不到對應配對 |
| 詐騙章節 | 未指定年齡 | 進入 08 章時自動切換為 **16 歲** | 16–17 歲是青少年受騙主要族群；同時示範查看程度變為每月總額時，防詐警示仍即時通知 |
| 家長不同意時的留言 | 一句通用留言 | 依類型：提前領出「先存到目標再說喔！」、大額消費「我們先一起討論看看」、新收款人「這個買家怪怪的，先不要轉」 | 讓情境更合理 |

## 3. 示範數字（預設設定：零用錢 $500、30/35/35、1:1、上限 $200／$600）

| 項目 | 數值 |
|---|---|
| 每週入帳 | 儲蓄 $150・需要 $175・想要 $175 |
| 起始罐子 | 需要 $115（已花早餐 $45＋公車 $15）・想要 $175 → 可以用的錢 $290 |
| 球鞋基金 | 目標 $1,800；我存的 $820；媽媽保留 $300 → 62% |
| 付款示範 | 珍珠奶茶 $70（想要罐）→ 存起來：我 +$70、媽媽 +$70 → 62% → 70%（+8%） |
| 達標示範 | 我存的 $1,200＋媽媽的配對 $600＝$1,800 |
| 外婆紅包 | $2,000 先進想要罐，再問要不要存 $500 到夢想 |
| 需要家長同意 | 單筆 $1,000 以上；新增收款人；夢想基金提前領出 |

## 5. 擱置中的議題

- **付款時「存起來」可能被拿來刷配對**：目前照規格書，付款時選「存起來」會觸發配對（每週上限限制成本）。是否改為「只配對實際存入夢想的錢」或「每天最多配對 N 次」，待組內討論。
- **用刷卡回饋配對**：可沿用 MMA 兒童帳戶既有的「父母回饋金自動轉存」機制，待討論。
- **信託**：照規格書顯示 15／18 歲分齡給付；頁面標示「信託商品條件需向永豐確認」。
